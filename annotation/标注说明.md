# 人工标注说明

## 一、任务概述

表中每一行是从一篇科研论文里抽取出来的一段文字。请判断这段文字**是不是作者关于"是否、如何使用生成式 AI 或 AI 辅助工具"的声明**；如果是，再标注它的几项属性。

- 共 350 条，预计用时约 3 小时，可以分几次完成，记得随时保存。
- 两位专家拿到的是同一份数据。**请各自独立完成，完成前不要相互讨论，也不要查看对方的结果**，否则无法计算标注者之间的一致性。
- 每一条**只依据这段文字本身**判断，不要推测原文其他部分的内容。文字可能是英文以外的语言，按原意判断即可。
- 拿不准时，选最贴近下文定义的选项，并在"备注"列写一句理由。

## 二、表格怎么填

打开 `GAID_annotation_expertX.xlsx`，只有一个工作表"标注"。

| 列 | 说明 | 怎么填 |
|---|---|---|
| 编号 | 条目编号 | 不要改动 |
| 位置 | 这段文字在论文中的位置：**AI声明专节**（标题本身就是 AI 使用声明的小节）、**致谢/声明/脚注**（致谢、各类声明、脚注、文末附注等）、**正文** | 不要改动 |
| 章节标题 | 这段文字所在小节的标题，可能为空 | 不要改动 |
| 待标注文本 | 抽取出的原文，可能夹带与 AI 无关的句子 | 不要改动 |
| decl | 是否为 AI 使用声明 | 下拉选 `1` 或 `0`，**必填** |
| pol | 极性 | decl=1 时**必填**，下拉选 `use` / `no_use` / `na` / `unclear` |
| tools | 作者使用的具名工具 | 手写；多个用分号 `;` 隔开；没有具名工具就留空 |
| LANG … UNSPEC（11 列） | 用途 | pol=use 时，适用的用途填 `1`，**至少填一项**；其余留空 |
| resp | 明确的责任声明 | 符合填 `1`，否则填 `0` 或留空 |
| rev | 声明作者审阅过 AI 输出 | 符合填 `1`，否则填 `0` 或留空 |
| nonuse | 明确否定 AI 参与了某些任务 | 仅 pol=use 时适用；符合填 `1`，否则填 `0` 或留空 |
| 备注 | 疑问或理由 | 选填 |

规则：

- **decl = 0 时，后面各列全部留空。**
- pol 不是 `use` 时，tools、11 个用途列和 nonuse 都留空。
- 黄色的列是要填写的列。可以用筛选或排序方便查看，但不要删除行，也不要修改前四列。
- 填好后把文件交回，文件名可以加上自己的名字，比如 `GAID_annotation_expert1_张三.xlsx`。

## 三、各字段的定义

### 1. decl —— 是否为 AI 使用声明（1 / 0）

**AI 使用声明**指论文作者本人说明：在准备这篇论文或开展论文背后的研究工作时，**是否、以及如何把生成式 AI 或 AI 辅助工具当作辅助手段来使用**。辅助的工作包括写作、编辑、翻译、检索或总结文献、编程、分析数据、制作图表等。

这类工具包括：聊天机器人和大语言模型（如 ChatGPT）、写作或翻译辅助工具（如 Grammarly、DeepL）、图像生成工具、编程助手、AI 文献工具，以及只笼统写成"AI"的情况。

以下也算声明（decl = 1）：

- **未使用的声明**，如 "No AI tools were used."
- 在 AI 声明小节标题下的**简短回答**，如 "None."、"Not applicable."

如果 AI 只以下列身份出现，**不算声明（decl = 0）**：

- 研究本身的**对象、方法、材料、对照或干预**。例如 "we evaluated ChatGPT's answers"、"a deep-learning model was trained"，或者方法部分写 "vignettes for the experiment were generated with GPT-4"。
- 资助方、基金项目、机构、公司、产品、期刊或人名中的一部分。
- 利益冲突声明或任职情况说明。
- 对他人研究的描述。
- 对 AI 的一般性讨论。
- 作者姓名缩写。例如作者贡献里的 "AI wrote the first draft"，这里的 AI 是人名缩写。
- 出版社或编辑部的通知。
- 文字只是一个标题，没有任何陈述。

**位置为"AI声明专节"时**：默认它是声明，除非它显然不是作者关于 AI 使用的陈述。

### 2. pol —— 极性

| 取值 | 含义 |
|---|---|
| `use` | 作者说明至少使用了一种 AI 或 AI 辅助工具来做某件事 |
| `no_use` | 作者说明没有使用任何 AI 或 AI 辅助工具（包括 "None"、"Not used"、"Nothing to declare"） |
| `na` | 整个回答就是 "Not applicable"、"N/A" 或同义表述 |
| `unclear` | 确实是声明，但无法判断是否使用了 AI |

特殊情况：作者说没有使用生成式 AI，但又提到自己用了某个 AI 辅助工具（如 Grammarly），选 `use`。

### 3. tools —— 作者使用的具名工具

只写作者**说自己用过**的、**有名称**的 AI 产品或模型：

- 写产品或模型名，不写厂商名："OpenAI ChatGPT" 写 `ChatGPT`。
- 版本号可以写在括号里，也可以不写，比如 `ChatGPT (GPT-4o)` 或 `ChatGPT`。
- 多个工具用分号隔开，如 `ChatGPT; Grammarly`。

不要写进来的：

- 笼统的描述，不是名称："AI tools"、"an AI chatbot"、"a large language model"。
- 只作为"未使用"提到的工具，或只作为研究对象出现的工具。
- 已经写出产品名时，只出现的厂商名。
- 非 AI 软件，如 Word、SPSS、BioRender、Canva、EndNote。

没有具名工具时留空。

### 4. 用途（11 列，仅 pol = use 时填写，可多选）

| 列 | 含义 |
|---|---|
| LANG | 编辑作者自己写的文字：语法、拼写、文风、清晰度、可读性、流畅度、精简、润色、校对、改写或转述、调整已有文字的结构 |
| TRANS | 不同语言之间的翻译 |
| DRAFT | 生成新文字：起草章节、摘要、标题、总结、提纲、投稿信或审稿回复 |
| LIT | 查找、筛选、总结或综合文献；核对或推荐参考文献 |
| IDEA | 头脑风暴、产生或完善想法、对稿件提出反馈或批评、研究设计建议 |
| CODE | 编写、调试或解释代码、脚本、公式、查询语句 |
| DATA | 数据分析、统计、数据提取、标注、处理，或解释结果 |
| VIS | 制作或编辑图表、图像、插图、图文摘要、示意图 |
| FORMAT | 排版稿件、参考文献或表格；检查是否符合期刊或报告规范 |
| OTHER | 其他明确写出的用途，如生成研究材料或试题、转录 |
| UNSPEC | 声明使用了 AI，但没写用途或写得很笼统，如 "assisted in manuscript preparation"、"writing assistance"、"in the writing process" |

注意：

- 对上面这类笼统说法，**不要**标 DRAFT。
- **只有在没有任何具体用途时才标 UNSPEC**，不要和其他用途同时标。

### 5. resp —— 明确的责任声明（1 / 0）

只有作者**明确表示**对内容或工作承担责任时才标 1，例如 "take full responsibility"、"are responsible for"、"remain accountable"。

只说作者完成了、审阅了或批准了工作，不算。

### 6. rev —— 声明作者审阅过 AI 输出（1 / 0）

作者说明自己审阅、编辑、检查、核实、验证、批准或监督了 AI 辅助产生的内容（或使用 AI 之后的内容），标 1。

### 7. nonuse —— 明确否定 AI 参与某些任务（1 / 0，仅 pol = use）

在声明使用了 AI 的同时，作者还**明确否定** AI 参与了某些任务或内容时标 1，例如：

- "AI was not used for data analysis"
- "no content was generated by AI"
- "the tools had no role in interpretation"

单独出现 "solely for language editing" 或 "all analysis was done by the authors" 这类说法，**不算**。

## 四、示例

| 位置 | 章节标题 | 文本 | 应填 |
|---|---|---|---|
| AI声明专节 | Declaration of generative AI and AI-assisted technologies in the writing process | During the preparation of this work the authors used ChatGPT (GPT-4o, OpenAI) and DeepL in order to improve readability and translate parts of the text. After using these tools, the authors reviewed and edited the content as needed and take full responsibility for the content of the publication. | decl=1；pol=use；tools=`ChatGPT (GPT-4o); DeepL`；LANG=1、TRANS=1；resp=1；rev=1；nonuse=0 |
| AI声明专节 | Generative AI statement | The author(s) declare that no Generative AI was used in the creation of this manuscript. | decl=1；pol=no_use；其余留空 |
| AI声明专节 | Use of AI tools | Not applicable. | decl=1；pol=na；其余留空 |
| 致谢/声明/脚注 | Acknowledgments | We thank J. Smith for technical help. Generative AI tools were used solely for language polishing; they were not used to generate scientific content or to analyse data. Figure 1 was created with Midjourney v6. | decl=1；pol=use；tools=`Midjourney (v6)`；LANG=1、VIS=1；resp=0；rev=0；nonuse=1 |
| 致谢/声明/脚注 | Funding | This work was supported by the National Artificial Intelligence Research Program (grant 2023-0042). | decl=0；其余留空 |
| 正文 | Methods | Responses to the 30 patient questions were generated with ChatGPT-4 and Gemini and rated by two physicians. | decl=0；其余留空（AI 是研究对象） |
| 正文 | Statistical analysis | Analyses were run in R 4.3. GitHub Copilot assisted in writing the analysis scripts, and the manuscript was proofread with Grammarly; all outputs were checked by the authors. | decl=1；pol=use；tools=`GitHub Copilot; Grammarly`；LANG=1、CODE=1；resp=0；rev=1；nonuse=0 |
| 致谢/声明/脚注 | Author contributions | AI and JS designed the study. AI wrote the first draft. All authors approved the final manuscript. | decl=0；其余留空（AI 是作者姓名缩写） |
